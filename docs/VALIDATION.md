# 검증 결과

## 수행

- 배포 C# 45개 파일: C# 파서 문법 검사 통과.
- Core 생산 코드와 검사 프로그램: Mono C# 컴파일·실행, 177개 assertion 통과.
- 원본과 메서드 본문 비교: 130개 기존 메서드 본문 동일. 별도 추출한 보스 패턴 6개 본문 동일. Editor 기존 검사 본문 유지.
- 의도적 변경: 무의식화 상태를 Core로 위임, 개별 패턴 호출 분기, Editor 검사 호출 분리.
- 신규 .meta GUID 중복·누락, Core의 Unity 비의존, 주 컴포넌트 파일, 이전 경로 검사 통과.
- 이전 도구: dry-run 비수정, 원본 스크립트 22개 GUID 유지, 사용자 씬·설정 유지, 재적용 유지, 중복 파일 발생 시 적용 전 중단 확인.

## 별도 확인 필요

- 실제 Unity 컴파일·Play·물리·화면·애니메이션: 이 환경에서 실행하지 않음.
- GitHub workflow는 제공했으나 원격 저장소에 게시하거나 실제 Actions를 실행하지 않음.
- .NET 8 프로젝트는 Core 파일을 그대로 포함하며, 이번 로컬 실행은 Mono로 동일 Core와 Program.cs를 컴파일한 결과.
- 플레이 시간 15~20분, 난이도·재미·회피 가능성: 실제 플레이로 측정.

Core 검사 통과를 Unity 전체 빌드나 재미 검증으로 해석하지 않는다.
