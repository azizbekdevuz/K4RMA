# SW02 수평 반달형 일섬 수정 · 2026-10-30

이번 명세는 기존 요청의 SW02 파도형 표현과 회피 설명을 대체한다. SW02는 기존 `SW02_AimedSlash.png` 한 장으로 표현하는 거대한 반달형 검기이며, 조준한 좌측 또는 우측으로 일정한 높이에서 직진한다.

## 구현

- 일반 2발·강화 3발에서 모두 1발로 변경했다. 추적 중에는 플레이어의 좌우만 확인하고, 고정 후에는 방향·원점·높이를 바꾸지 않는다.
- 파란 추적 전조는 기본 0.4초(강화 시 0.328초)다. 주황 고정 전조는 최소 0.9초이며 실제 피해 코어 뒷면 밖까지의 거리 ÷ (이동속도 × 0.9)에 반응 여유 0.35초와 물리 2틱을 더한다. 지면 마찰에 10%의 이동 여유를 두며 강화 배율로 줄이지 않는다.
- 실제 Collider 높이 3.1, 점프속도 26, 중력 58.86 기준 연속 계산상의 일반 점프 상승량은 5.742439다. 검기의 하단은 0.05, 상단은 9.442439, 높이는 9.392439, 폭은 약 5.635464월드 단위다. 실제 물리 점프의 최고점은 별도 측정한다.
- 검기 크기는 점프속도·중력·실제 Collider 높이에서 계산한다. 코어의 알파 경계 `Rect(40,28,1296,380)`를 실제 피해 사각형의 중심·폭·높이에 맞춘다. 투명한 모서리도 사각형 공격 범위에 포함되며 전조는 이 전체 범위를 보여 준다.
- 좌우 모두 이미지 회전은 0도다. 오른쪽 발사는 `flipX=true`, 왼쪽 발사는 `false`로 원본의 밝은 칼날 선두를 진행 방향에 맞춘다. 이동 중 크기나 회전 변화, 상하 진동, 추적, 별도 테두리, 발광·잔상 복제를 추가하지 않는다.
- 발사 중심과 종료 중심을 검기 반너비만큼 안쪽으로 제한해 피해 코어 전체가 경기장 안에 남는다. 안쪽으로 발사할 때에는 뒤편에 플레이어 너비+0.2의 공간을 확보한다. 벽 바깥쪽을 향해도 검기 반너비 이상의 이동 거리를 남겨 수명 0으로 즉시 사라지는 경우를 방지한다.
- 속도 40·피해 배율 1.15와 기존 1.1초 기준 회복(일반 0.792초/강화 0.64944초)은 유지한다. 실제 패턴 시간은 고정 전조와 경기장 경계까지의 거리에 따라 달라진다. 비정상적으로 느린 설정으로 watchdog 안에 끝낼 수 없는 SW02는 AI 선택에서 제외한다.

## 회피

플레이어 속도는 14, 관통베기 이동거리는 8월드 단위다. 보스 본체에는 이동을 막는 Collider가 없고 Stage 2~4의 실제 지형은 평지와 좌우 벽이다. 상승 기술을 잃은 계승 상태에서도 전조가 고정된 뒤 보스 뒤쪽으로 걸어갈 수 있게 시간을 계산한다. 맵 끝에서는 단순히 보스 중심을 넘는 대신 실제 검기 뒷면과 플레이어 반너비까지 벗어나는 좌표를 사용한다.

일반 점프나 지상 상승베기 단독으로는 상단을 넘을 수 없다. 상승베기를 보유한 경우 점프 도중 상승베기로 속도를 다시 올리는 조합은 상단 회피가 가능하다. 자동 테스트는 보유 능력을 실제로 사용하고 Collider의 발높이와 피해 여부를 검사한다. 능력에 의존하지 않는 도보 경로도 별도로 검사한다.

SW04의 기존 독립 검막과 반격 루트는 유지한다. SW02 준비·발사·회복이 검막 수명이나 다른 공격의 상태를 덮어쓰지 않으며, 일시정지·중단 시 양쪽 표시와 판정을 정리한다.

## 평타·거리 유지

기존 평타 사거리는 10월드 단위인데 AI 선호 거리가 공간 배율 적용 후 14였다. 정지한 플레이어에게 스킬만 사용해도 조건이 충족되어 평타를 쓰지 않는 상황이 가능했다. 선호 거리를 기본 9로 낮추고 `swordPreferredDistance`로 조절한다. 평타 피해·사거리·쿨다운은 유지하며 `swordSkillsBetweenBasics`로 완료한 스킬 사이 평타 삽입 주기를 조절한다.

후퇴는 5월드 미만·최대 0.4초·최대 3월드·쿨다운 4.5초·직전 후퇴 후 공격 완료 조건과 벽/바닥 검사를 유지한다. 회복 중 후퇴로 반격 기회를 없애지 않는다. 관측은 함수 호출 횟수와 별개로 실제 Transform 이동을 기록한다.

관통베기는 실제 `BeginDirectionalSlash` 실행 결과 이동거리 8월드와 일치했다. 도보 시나리오는 상승·관통베기를 사용하지 않는다. 벽 바깥 방향 발사도 최소 검기 반너비를 이동하도록 해 수명 0 즉시 제거를 막았으며, 실제 양쪽 경계 시나리오에서 각각 1발/약 0.10초 이동을 관측했다. 모든 검기의 선두 피해 경계가 경기장 경계에서 종료했다.

기존 발사 수는 일반 2/강화 3, 수정 후 실제 발사 수는 전 시나리오에서 1이다. 수정 전 코드의 프레임 반올림 전 전체 시간은 일반 4.282초/강화 4.64904초였다. 수정 후 보스 x=20, 플레이어 x=30 또는 x=10인 대칭 조준 사례의 실제 전체 시간은 일반 3.250초/강화 3.050초다. 전방 8월드 도보 사례는 3.050초, 벽 바깥 방향은 2.400초, 반대쪽 끝에서의 도보 사례는 8.650초다. 이제 조준 고정 시간과 경계까지 거리에 따라 패턴 길이가 달라진다. 회복은 실제 일반 약 0.800초/강화 약 0.650초로 기존 배율을 유지했다.

SW01 낮음/높음 2발, SW03 기존 연사와 검흔 안전 간격/3초 유지, SW04 독립 검막과 순차 4발 반격, SW05 중앙 천장/7회×15발/방어막·착지·회복 및 다른 보스 타입은 기존 전체 회귀 검사로 확인했다. 작업 시작 당시 Runtime과 비교해 새로 달라진 런타임 파일은 위 표의 `KarmaEnemy.SwordWave.cs`, `KarmaBossAttack.cs`, `KarmaWaveArtwork.cs`, `KarmaEnemy.StateMachine.cs`, `KarmaBossTuning.cs` 5개뿐이다. 보스 자신의 `DamageBounds` 구현은 시작 시점과 같다.
