## 새 실행 구조

1. 도약 준비 0.8초 → 공중 이동 0.5초.
2. 방어막 생성 후 기존 개별 전조를 유지한다(일반 0.45초 / 강화 0.369초).
3. 정확히 **7묶음**을 실행하고 매 묶음 **4~8발**을 독립적으로 뽑는다. 총량은 **28~56발**이다.
4. 첫 발사를 기준으로 +0,+1,+2,+3,+4,+5,+6초 목표 슬롯을 사용한다. 이전 검기가 날아가는 동안 다음 전조를 준비하고, 전조 전체를 마친 뒤 발사한다. 프레임 반올림이 누적되지 않도록 절대 전투 시각을 사용한다.
5. 각 검기의 실제 수명은 **자신의 발사 위치·방향·속도에서 경기장 경계를 만날 때까지의 시간**이다. `WaveLife`나 마지막 정리 시각으로 자르지 않는다.
6. 모든 묶음의 실제 공격 객체가 비활성화된 것을 확인한 뒤 방어막 해제 → 기존 0.5초 착지 → 기존 회복으로 진행한다.

계획용 수명 상한은 경기장 대각선 `sqrt(70²+24²) / 32 ≈ 2.313초`이다. 이는 모든 가능한 위치·방향을 포함하는 유한한 상한이고, 개별 검기는 x/y 경계 중 먼저 도달하는 시점으로 더 짧아진다. 경기장 밖으로 무한히 비행하지 않는다. 전조 끝에도 같은 개별 수명을 적용한다.

상하좌우·대각선 분산, 조준/주변 공격 혼합, 시드 재현, 실제 물리 이동·점프 경로 보존과 각 검기의 독립 contact 기록은 유지했다. 기존 투사체는 피해 접촉 기록으로 중복 피해를 막고 경계까지 계속 비행하는 구조이며, 이번 작업에서 충돌 후 소멸 규칙이나 장애물 충돌 기능을 새로 추가하지 않았다.
