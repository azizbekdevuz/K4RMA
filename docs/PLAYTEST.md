# 마지막 수호자의 가르침 — 플레이 검증

## 설치와 컨셉

- [ ] README의 이전 도구로 모듈 구조를 적용하고 Console 컴파일 오류 없음. 기존 .meta·씬·Config 유지 확인.
- [ ] 시작 화면이 마지막 수호자의 시험·기술 무의식 내용, 최종 상대가 마지막 수호자, 감옥·주민 연출 없음.
- [ ] 시작 체력 4,800 / 8,000 / 11,000 / 18,000 확인(기본 프로필).
- [ ] 새 Config의 보스 난이도·화상 설정이 Inspector에 표시.
- [ ] `K4RMA → 로직 검사` 통과.

## 난도

- [ ] 전투 시작 전 상대는 대기, 수련장 진입 또는 선제 공격으로 전투 시작.
- [ ] 60%·25% 체력에서 페이즈 표시·탄막·강타·돌진 변화.
- [ ] 추가 지면 강타·재돌진에 예고가 보이며 회피 가능.
- [ ] 발판 위에 머물 때 추적 연사가 현재 위치를 조준.
- [ ] 좌우 끝으로 도망가도 상대가 접근하거나 공격함.
- [ ] 공격 중단과 회피 후 접근할 빈틈 존재.

## 화염 방벽

빠른 확인: 화염·보호막을 먼저 무의식화해 세 번째 시험의 방벽 사용을 기다리기.

- [ ] 공격하지 않고 기다리면 화상 없음.
- [ ] 검으로 방벽 적중 → 화상 표시·즉시 피해·외측 넉백.
- [ ] 공격 중단 후에도 약 0.6초마다 피해·넉백, 3.6초 후 종료.
- [ ] 재공격 시 지속 시간 갱신, 매 탄환마다 즉시 중첩 피해가 생기지 않음.
- [ ] 불씨·검기 등 원거리 무의식 공격으로도 방벽 반격 발생.
- [ ] 일반 피격 무적 중에도 화상 틱 적용, 보호막 무의식의 피해 감소 적용.
- [ ] 넉백 사이에 조작 회복, 방벽 종료 후 재접근 가능.
- [ ] Esc 중 화상·이펙트 시간 정지, 재개 후 남은 시간부터 진행.
- [ ] 사망·재도전·상대 처치 후 화상 제거.
- [ ] 화상으로 사망한 프레임에 승리 화면으로 잘못 바뀌지 않음.

## 무의식 관통

- [ ] 불씨·검기가 상대를 맞힌 후에도 뒷쪽으로 날아감.
- [ ] 탄환 하나가 겹쳐 있는 프레임마다 상대 HP를 계속 깎지 않음.
- [ ] 액티브 화염탄은 적중 시 소멸.
- [ ] 충격파는 전체 범위 효과로 표시.
- [ ] 화염·돌진·보호막 6가지 무의식화 순서에서 액티브 상실·무의식·합성 해금 정상.

## 시간 기록

첫 시험 ___분 / 둘째 ___분 / 셋째 ___분 / 마지막 수호자 ___분
총 ___분 / 재도전 ___회 / 무의식화 순서 __________

- [ ] 목표 3분 / 3분30초 / 4분 / 5분30초와 실제 성공 전투 기록 비교.
- [ ] 전체 목표 15~20분과 실제 플레이 시간 비교.
- [ ] 체력이 지루하게 길면 체력 배율을 낮추고 패턴 난도 유지.
- [ ] 짧게 끝나면 실제 DPS를 참고해 해당 상대 체력 조정.

실측 전에는 15~20분 달성을 확인한 것으로 간주하지 않음.

## 9월 30일 추가 패턴 검증 (Unity 실행 필요)

- Q 화염탄/무의식 불씨 적중: 적에게 화상 시간·주황 틱, 약 0.5초 간격 HP 감소. 화상만으로 적 위치는 바뀌지 않음. 연속 적중에도 틱이 중첩되지 않음.
- 단독 화염 해금: 화염 탄막 대신 바닥 예고 후 메테오. 중앙과 좌우 추가 낙하. 직접 충돌/폭발 중복 피해 없음. 피격 시 플레이어 넉백. 보호막·돌진 무적으로 막았을 때 넉백 없음.
- 적 보호막에 검 100, 감쇠0.3: 보스30 피해, 반사 누적70. 0.65초 뒤 방사탄 각각70. 추가 공격 누적 확인. 화상 틱은 반사 누적을 늘리지 않음. 충격파는 회피 가능.
- 돌진+보호막: 돌진 중 감쇠, 도착마다 사방 충격파. 재돌진 때도 예고와 도착 충격파.
- 세 능력 해금 전 삼중 합성 없음. 마지막 수호자에게 모두 무의식화하면 삼중 합성이 순환에 포함됨.
- 삼중 합성 준비/돌진 중 HP 감소 없음(화상 포함). 주변 화염 피해. 돌진 방향은 준비 종료에 한 번 고정.
- 왼쪽/오른쪽 벽 각각 유도: 벽 닿은 위치에서 폭발, 마지막 수호자이 반대 방향으로 넉백, 3.5초 기절, 방어막 소멸, 접촉 무피해, 공격 피해 1.5배. 이후 정상 복귀.
- 점프로 벽 폭발을 피하고 넉백된 마지막 수호자에게 접근 가능한지 실제 점프 타이밍 점검.
- 저프레임에서도 운석/삼중돌진 구간 충돌 누락 없음.
- 일시정지 중 화상/운석/기절 정지. 사망·재도전 후 이전 운석·충격파·상태 잔존 없음.
- 기존 설정 체력999/검100 같은 사용자 수정값이 코드 덮어쓰기 후 유지되는지 확인. Generated를 삭제하거나 난이도 초기화 메뉴를 누르지 않음.

## 10월 1일 혼합 공격 검증

- 화염 무의식화 후 보스 HP >60%, 60% 이하, 25% 이하에서 메테오 수가 각각3/5/7인지 확인.
- 낙하 경고가0.4초마다 추가되고 각각1.1초 예고를 거치는지 확인. 벽 양끝에서도 중복 낙하 없는지 확인.
- 기본 반경에서 낙하 지점 사이로 이동해 피할 수 있는지 확인. 마력탄을 피하면서 이동 가능한지도 실제 플레이 확인.
- 혼합 사용 켜짐: 1페이즈 추가탄0, 2페이즈1, 3페이즈2. 메테오/두 보호막에만 추가.
- 노란 조준선이0.5초 먼저 보이고, 예고 후 이동해도 탄의 방향이 재추적되지 않는지 확인.
- 일반 돌진·합성 돌진에 새 추가 마력탄이 섞이지 않는지 확인.
- 마지막 메테오가 끝나기 전 다음 패턴이 시작하지 않는지 확인. 마지막 적중으로 운석이 공중에서 터져도 진행이 막히지 않는지 확인.
- 마지막 수호자 삼중 합성 시작·벽 충돌 때 적 탄환 정리. 기절 중 새 공격 없음. 플레이어 관통탄은 유지.
- 사망/재도전/일시정지 중 예약된 추가 탄·예고가 잘 정리 또는 정지되는지 확인.
- 혼합 사용 끄고 동일 체력·순서로 재시도하여 난이도 비교. 실제 재미·회피 가능성은 Unity 플레이로 검증해야 함.

## 최신 추적 메테오 검증

- 추적 옵션이 켜진 상태로 서 있으면 모든 운석이 예고 시작 때 그 위치를 노리는지 확인.
- 첫 예고 뒤 좌우로 이동: 다음 예고는 새 위치에 생기고, 이전 예고는 그대로 남는지 확인.
- 낙하 중 방향 변경: 운석이 플레이어를 따라 꺾이지 않는지 확인.
- 멀리 이동해도 대기 중인 운석이 처음 패턴을 시작한 위치에만 몰리지 않는지 확인.
- 일시정지 중에는 새 위치 샘플과 예고 시간이 진행하지 않는지 확인.
- 추적 끄면 이전7개 고정 낙하 지점으로 복귀하는지 확인.
- 기존 에셋의 예고 설정 유지 확인.0.9초로 조정해 느린 기본 마력탄과 함께 회피 가능한지 플레이 검증.

## 스토리·용어·최종 수호자 확인

- 시작 화면: 스승은 시험 제안자, 전투 상대는 수호자로 안내.
- 기술 카드의 의식/무의식 표기, 선택창의 무의식화 설명, 수련문 안내 확인.
- 세 번째 무의식화 전환 화면에서 마지막 수호자 안내 확인.
- 최종 상대가 백발·지팡이의 스승이 아니라 투구·견갑·핵을 지닌 수호자로 생성되는지 확인.
- 마지막 수호자의 삼중 합성, 벽 충돌 넉백·기절은 기존대로 동작.
- 엔딩의 시험 통과·무의식화 순서·마지막 수호자 기록 확인.
- 기존 체력·공격력 에셋 값과 무의식화 진행이 유지되는지 확인.
- 발표 설명: 첫 잔재 기반 전투 타입 변형은 목표 설계이며 현재 구현은 기술 집합 기반 합성이라는 점 구분.
