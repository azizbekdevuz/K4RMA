# K4RMA UI / Screens v3
기준: gameplay-hall-less-vegetation-v7. 고유화 용어 고정. 메인 메뉴 및 고유화 선택은 v3 수정본 사용.

## 공통 아트 규칙
- deep navy / indigo / dark teal, 저채도 원경, 아이보리 글자와 얇은 선.
- 겹치는 안개와 달빛으로 깊이 확보. 가지·식생은 모서리의 작은 덩어리.
- 캐릭터는 검은 묶음 머리·남색 수련복·아이보리 허리띠·일본도 고정.
- 큰 사각 버튼·카드 테두리·설명 문단 제거. 선택 상태는 작은 crescent와 은은한 명도 변화.
- 모든 화면 16:9 구성. 권장 Unity reference resolution 1920×1080. 실제 PNG 해상도는 file-index.json.
- 본 묶음은 UI 원화/화면 Mockup/구성요소 atlas. Unity Scene, Canvas, 동작하는 메뉴 구현은 포함하지 않음.
- 이미지 속 문자는 배치 참조. 실제 서비스용 문자는 PNG에 굽지 않고 TMP로 따로 출력. 자간/읽기 크기/현지화는 Canvas에서 조정.

## 상태와 연결
- 시작 → 시련1 → 일반 시련 클리어 → 고유화 선택 → 고유화 완료/잔재 전달 → 월광 전환 → 다음 시련.
- 시련4 완료 → 최종 클리어. 마지막 상대는 수호자, 스승 없음.
- 고유화: 검기→관통베기 / 상승베기→체공 / 방어→반격. 원형의 잔재는 다음 수호자에게 누적 전달.
- 첫 고유화 원형이 이후 수호자의 주 타입을 결정, 이후 다른 원형이 구조/패턴을 추가.
- 선택창은 첫 고유화 전 3개 항목 상태. 이후 이미 고유화한 원형은 목록에서 제거: 3→2→1개.
- 2개 남을 때 중심 기준 x43/57%; 1개 남을 때 x50%. 3개는 x36/50/64%.
- 현재 선택만 결과 한 줄 출력. 결정 후 중복 입력 잠금, 잔재 전달 연출 완료 후 다음 시련.
- 일시정지 화면의 큰 공격은 멈춘 배경으로 사용. 설정에서 되돌아갈 위치는 메뉴/일시정지 진입 경로 유지.
- 이어하기는 저장값이 있을 때 활성화. 저장 없는 경우 숨김 또는 낮은 명도.
- 게임 오버는 다시 도전 / 메인 메뉴. 재도전 상태 복원 범위는 기존 게임 코드에 맞춤.

## Unity 적용 명세
- UI 공통 배경은 UI/menu-background-clean.png 사용, Mockup에 표시된 글자·아이콘은 런타임에 따로 배치.
- ScreenSpaceOverlay Canvas, CanvasScaler ScaleWithScreenSize, 1920×1080, Match0.5부터 실제 화면 확인.
- 해상도/비율 변경 시 위·아래 HUD 별도 앵커, 중앙 선택 그룹은 center. 화면 모서리 안전 여백 최소3%.
- 화면 배경과 UI/TMP는 분리. Mockup 전체 PNG를 최종 버튼 입력 화면으로 취급하지 않음.
- Panel veil은 별도 반투명 남색 Image. 입력 차단은 modal 동안만. 시각 강조와 포커스 이동 함께 처리.
- 화려한 glow 대신 선택 밝기·부분 arc·작은 crescent. 선택 변경 100~160ms, 메뉴 fade 200~350ms는 제안 타이밍.
- UI atlas는 실제 alpha 사용. Sprite Editor 수동 Slice, 작은 심볼용 충분한 padding. Grid 자동 분할은 결과 확인 후.
- thin-line track/fill, circle/diamond는 가능하면 Unity 기본 primitive 또는 벡터로 재구성하여 DPI 선명도 유지.
- Skill icons 권장32~48px HUD, 선택64~96px. 제목32~44px, 메뉴24~28px, 보조20~24px at1080p부터 검토.
- 모션 배경: 달/원경 고정에 가까움, 안개 느리게 흐름, 가까운 실루엣 약한 parallax. 메뉴 중앙 뒤 높은 대비 금지.
- 장면 전환 PNG는 하나의 중간 상태. 실제 전환은 UI mask/shader 또는 추가 프레임으로 완성.
- 고유화 잔재의 원형(수평/상승/원형)은 선택에 따라 교체. 확인 그림은 검기 사례.
- 스프라이트 절단·TMP 한글 폰트·키보드/패드 포커스·Unity 실행 검증은 이번 이미지 제작 범위에 포함하지 않음.
