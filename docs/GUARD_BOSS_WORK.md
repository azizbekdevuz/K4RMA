## 바로 실행

상단 **K4RMA → 방어형 연습**에서 원하는 항목을 선택하면 Play에 진입한다.
일반 스테이지를 먼저 클리어할 필요가 없다.

| 메뉴 | 용도 |
|---|---|
| 전체 패턴 자연 전투 | 방어 → 검기 → 상승베기를 계승한 최종 방어형과 정상 AI로 전투 |
| GD01 자동방어막 | 시작부터 방어막 유지; GD02 패링으로 깨진 뒤 재생성 |

| GD03 분열 방패 | 4개 시차 추적 발사·정지·피격 가능한 고정 경로 복귀 |
| GD04 계단 상승 | 한 방향으로 높아지는 지면 6개·상승 판정·지형 위 이동 시험 |
| GD05 결계 생존 시험 | 결계와 피격 집계·성공/실패 결과 반복 |
| 다시 시작 / F6 | 현재 연습을 처음부터 재시작 |
| 체력 자동 회복 | 패턴 관찰용 선택 기능. 실제 피격·기절·결계 피격 집계는 그대로 발생 |
| 연습 종료·타이틀 | 반복 실행을 해제하고 타이틀로 복귀 |

A/D 이동, Space 점프, J 기본 공격, K 반격, Esc 일시정지.
연습은 세 기술을 이미 고유화한 최종 상태이므로 원형 Q/Shift/E 대신 고유화 기술을 사용한다.
자동 회복은 기본 꺼짐이며 사망을 되돌리는 무적 기능은 아니다. 사망하면 F6으로 재시작한다.
Play 종료 시 연습 상태가 해제되고, 연습 중 스크립트를 다시 컴파일하면 현재 항목을 처음부터 시작한다.
연습 도구는 설정 에셋의 HP·피해·밸런스를 바꾸지 않으며 Windows 빌드에는 포함되지 않는다.

## 이번 수정

  후속 충격파는 검기를 계승하고 체력이 50% 이하일 때만 발동한다. 기본 방어형·상승베기만 계승한 형태에는 없다.
  충격파를 일반 반격해도 GD01은 유지되고 보스는 무력화되지 않는다.
- GD03: 4개를 0.3초 간격으로 발사한다. 전진은 플레이어 추적, 복귀는 멈춘 지점에서 보스까지 고정된 직선이다.
  처음에는 온전한 큰 방패가 0.5초 동안 회전하며 날아가 피해만 준다. 도착한 실제 방패 위치에서
  파편들이 0.28초 동안 퍼지고, 같은 파편들이 조준 예고 뒤 추적을 시작한다. 분열 연출에는 피해가 없다.
  추적은 피해·기절, 복귀는 기절 없이 피해만 준다. 각 방패·각 구간당 한 번만 맞는다.
  D 모양+B 문양의 전용 파편을 사용하며, 조준·추적은 붉게 달궈진 금속/붉은 잔상,
  정지·복귀는 식은 금속/짧은 회색 잔상으로 구분한다. 기존 최대 크기와 중심을 유지한다.
- GD04: 6개 지면이 0.22초 간격으로 한 방향을 따라 높아진다. 완성 뒤에는 올라설 수 있는 지형이다.
  GD01이 남아 있고 플레이어가 공격 범위 안의 후방으로 피하면, 지면을 유지한 채 반대로 돌아 GD02를 한 번 잇는다.

  각 지면의 상승 피해, 이미 위에 있는 플레이어의 위치 보존, 정면 방어, 경계 배치, 관통베기 차단을 확인한다.
- GD05: 노란 반원 보호막과 곡면 지붕 안에서 낮은 파동·낙하 봉인·양쪽 협공·바닥 봉인·높낮이 연속 공격을 섞는다.
