# 이번 소스 정리

## 변경

- 기존 Runtime 단일 폴더에서 기능별 하위 폴더로 분리.
- Player·Enemy·Game·Essences·HUD를 역할별 partial 파일로 분리.
- 보스 실행 분기를 메테오·돌진·보호막·지면 강타·연사·삼중 합성 파일로 분리.
- Unity 독립 `KarmaProgressionState`와 `K4RMA.Core` 어셈블리 추가.
- 외부에서 선택 순서 List를 바꿀 수 없도록 읽기 전용 뷰 제공.
- 기존 씬 생성·초기화 메뉴 유지, 검사 코드 별도 Editor 파일로 분리.
- Git 무시·개행·코드 서식·PR 템플릿·Core CI 추가.
- 안정적인 신규 .meta 제공, 기존 프로젝트 GUID를 보존하는 이전 도구 추가.

## 유지

클래스명·네임스페이스·설정 필드명, 기존 이동·검·기술·패시브·보스전 로직. 기존의 첫 잔재 기반 보스 타입 설계는 이번 정리로 새로 완성된 것이 아니다.

## 이전

파일을 직접 중복 복사하지 말고 README의 이전 도구를 사용한다. 원래 프로젝트의 `.meta`를 새 배포본의 `.meta`로 덮어쓰지 않는다.
