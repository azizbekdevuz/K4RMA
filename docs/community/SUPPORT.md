# K4RMA 도움말 및 지원

[한국어](SUPPORT.md) | [English](SUPPORT.en.md)

K4RMA는 대학 팀이 개발 중인 2D 액션 게임 프로토타입입니다. 상시 고객지원, 답변 시간 또는 플랫폼별 호환성을 보장하지 않습니다.

- **설치·실행:** [README.md](../../README.md)와 [docs/planning/PROTOTYPE.md](../planning/PROTOTYPE.md)를 먼저 확인하세요.
- **일반 게임 버그:** [GitHub 이슈](https://github.com/azizbekdevuz/K4RMA/issues/new)로 신고하세요. Unity 버전, 운영체제, 재현 절차와 로그를 작성하고 개인정보는 제외하세요.
- **기능 제안:** [GitHub 이슈](https://github.com/azizbekdevuz/K4RMA/issues/new)에 제안 내용을 작성하세요.
- **보안 취약점:** 공개 이슈가 아닌 [SECURITY.md](SECURITY.md)를 따릅니다.
- **라이선스/에셋 사용:** [LICENSE.md](../legal/LICENSE.md), [THIRD_PARTY_NOTICES.md](../legal/THIRD_PARTY_NOTICES.md), [GOVERNANCE.md](../collaboration/GOVERNANCE.md)를 확인하고 권리자 승인을 받으세요.

외부 기여는 사전 협의 대상이며 자동으로 수락되지 않습니다.
