# K4RMA Community Pack — Pre-merge Checklist

[한국어](REVIEW_BEFORE_MERGE.md) | [English](REVIEW_BEFORE_MERGE.en.md)

**This is review collateral, not necessarily a file to commit to the game repository.**

- [ ] Obtain documented authorization from all relevant rights holders for ownership, publication, commercialization and proposed LICENSE language.
- [ ] Audit actual source, providers, AI usage and license terms across `Assets/Arts/**`.
- [ ] Confirm whether any third-party/Unity Asset Store assets can be published as **raw source files**.
- [ ] Add exact required license texts and notices for fonts, audio, source and packages.
- [ ] Review applicable university and course distribution rules.
- [ ] Update outdated “license undecided” and original-planning language in both READMEs.
- [ ] Correct stale status in `docs/PROJECT_CONTEXT.md` and other initial planning records.
- [ ] Establish a real private conduct/security contact channel and publish verified details.
- [ ] Confirm GitHub labels `bug` and `enhancement` exist.
- [ ] Check if GitHub Private vulnerability reporting is enabled.
- [ ] Verify default branch is `main`; validate template hyperlinks.
- [ ] Validate YAML schemas, Markdown links and any relevant Unity verification.

A LICENSE notice does not cure improper historic publication of third-party assets.
