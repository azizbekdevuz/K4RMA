# K4RMA Support

[한국어](SUPPORT.md) | [English](SUPPORT.en.md)

K4RMA is a university team's in-development 2D action game prototype. Continuous support, response times and compatibility across platforms are not guaranteed.

- **Getting started:** [README.en.md](../README.en.md) and [docs/PROTOTYPE.md](PROTOTYPE.md).
- **Ordinary game bugs:** Use the [bug report form](../.github/ISSUE_TEMPLATE/bug_report.yml). Include editor version, OS, reproduction and sanitized logs.
- **Feature proposals:** Use the [feature request form](../.github/ISSUE_TEMPLATE/feature_request.yml).
- **Security vulnerabilities:** Follow [SECURITY.en.md](SECURITY.en.md), not public issues.
- **Licensing and assets:** Review [LICENSE.en.md](LICENSE.en.md), [THIRD_PARTY_NOTICES.en.md](THIRD_PARTY_NOTICES.en.md), and [GOVERNANCE.en.md](GOVERNANCE.en.md) and obtain rights-holder approval.

Outside contributions require prior coordination and are not automatically accepted.
