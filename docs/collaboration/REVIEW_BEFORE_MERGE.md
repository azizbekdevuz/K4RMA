# K4RMA 커뮤니티 파일 적용 전 점검표

[한국어](REVIEW_BEFORE_MERGE.md) | [English](REVIEW_BEFORE_MERGE.en.md)

**이 문서는 저장소에 반드시 커밋해야 하는 파일이 아닙니다.** 팀 승인 후 삭제하거나 `docs/`에 보관해도 됩니다.

- [ ] 4인 팀의 각 저작자/권리자가 소유·공개·상업화 권한과 LICENSE 표현에 서면 동의함
- [ ] `Assets/Arts/**` 전체의 실제 원천·제공처·AI 사용·라이선스 확인
- [ ] Unity Asset Store 등 제3자 에셋의 **공개 원본 재배포** 허용 여부 확인
- [ ] 폰트·오디오·코드·패키지의 필수 고지 문안과 라이선스 파일 추가
- [ ] 과제/대학의 배포 조건 확인
- [ ] `README.md`·`README.en.md`의 오래된 “라이선스 미정” 및 초기 계획 내용을 최신 상태로 갱신
- [ ] `docs/planning/PROJECT_CONTEXT.md` 등 초기 기획 문서의 상태 표시 갱신
- [ ] 팀 전용 비공개 보안/행동 신고 채널 확정 및 문서에 구체적으로 기재
- [ ] GitHub 이슈 라벨 `bug`, `enhancement` 존재 여부 확인
- [ ] GitHub의 Private vulnerability reporting 사용 가능 여부 확인
- [ ] GitHub 기본 브랜치가 `main`인지 확인 후 템플릿/링크 검사
- [ ] YAML 스키마, Markdown 링크, 로컬 Unity 검증(해당 시) 확인

**중요:** 권리 감사가 끝나지 않은 상태에서 LICENSE를 올린다고 외부 자료 문제가 해결되는 것은 아닙니다. 공개 저장소의 기존 업로드 사실도 소급하여 정당화되지 않습니다.
