# 보스 패턴 수동 플레이 검증

2026-10-22 기준. 이전 메테오/화염 돌진 체크리스트는 현 기획에 해당하지 않아 대체했다. 세부 수치는 [보스 패턴 문서](BOSS_PATTERNS.md)의 초기 정책을 기준으로 한다.

## 시작과 진행

- [ ] 저장소 루트를 Unity 6000.6.2f1로 열고 빈 씬 Play → 타이틀 → Enter로 시작한다.
- [ ] Stage 1 근접 검술 → 3회 고유화 → Stage 4 → 승리 흐름을 확인한다.
- [ ] 6가지 고유화 순서에서 첫 타입이 유지되고 후속 패턴이 독립 해금된다.
- [ ] 기존 Config의 HP/폰트/재질/기술 설정이 유지된다. 의도하지 않은 난이도 초기화를 하지 않는다.

## 검기형

- [ ] SW01 낮은 검기와 높은 검기의 폭·높이·발사 순서를 읽고 이동할 수 있다.
- [ ] SW02 추적/고정 전조를 구별하며 고정 뒤 보스 뒤로 넘어가도 발사 방향이 바뀌지 않는다.
- [ ] SW03 검흔 사이/바깥으로 이동할 공간이 있고 마지막 상승 뒤 회복이 시작된다.
- [ ] SW04 다단히트로 무제한 반격하지 않고, 검막 종료 후 검과 방어가 제거된다.
- [ ] SW05 체공 무적 중 생존 가능하며 종료 시 검 제거 → 방어 해제 → 착지 → 회복 순서를 지킨다.

## 상승베기형

- [ ] UP01 상승/낙하 경로를 읽고 착지 충격파를 점프로 넘을 수 있다.
- [ ] UP02 고정 후 낙하/수평 이동으로 피할 수 있고 연속 선택하지 않는다.
- [ ] UP03 등 뒤나 전방 범위 밖으로 이동할 시간이 있고 소멸 연출에 피해가 남지 않는다.
- [ ] UP04 방어는 착지까지 유지되고 착지 시 충격파와 파편이 중복되지 않는다.
- [ ] UP05 지상/공중/지상/최종 낙하 사이에 점프·착지·재점프 시간이 있다. 탈진 때 실제로 접근해 공격할 수 있다.

## 방어형

- [ ] GD01 생성 예고/활성/만료가 보이며 무한 중첩하지 않는다.
- [ ] GD02 패링 성공은 방어막 파괴/무력화, 실제 피격은 방어막 갱신, 회피는 기본 정책에서 갱신하지 않는다.
- [ ] GD03 전체 스킬 중 한 번만 피해/기절하며 복귀 조각은 피해가 없다. 기절 뒤 다음 공격이 확정 적중하지 않는다.
- [ ] GD04 전방 상승 구간만 피해가 있고 유지 벽은 이동만 막는다. 관통베기로 벽을 통과하지 못하고 생성 시 지형에 끼이지 않는다.
- [ ] GD04 뒤쪽 공격이 정면 방어에 막히지 않으며 맵 구석에 탈출 불가능한 공간을 만들지 않는다.
- [ ] GD05 배치 보호, HUD 피격/허용/남은 공격 수, 성공 공격 기회, 실패 폭발 예고가 보인다.
- [ ] 허용 피격 초과 직후가 아니라 마지막 공격 종료 후에만 시험 결과가 나온다.

## 공통 종료와 가독성

- [ ] 전조의 표시 폭/높이/경로가 실제 판정과 맞고 1920×1080 HUD가 잘리지 않는다.
- [ ] 일시정지 중 전조·사출·방어막·기절·결계 시계가 정지하고 재개 시 이어진다.
- [ ] 각 패턴 전조/공격/회복 도중 사망·타이틀 복귀·재시작 후 공격·방벽·이동 제한이 남지 않는다.
- [ ] 저프레임에서도 빠른 검/횡단 공격이 플레이어를 뚫고 피해를 누락하지 않는다.
- [ ] Windows 빌드에서 같은 흐름을 확인한다. 평균 FPS, 전환 시간, 스테이지별 전투 시간과 총 플레이 시간을 기록한다.
