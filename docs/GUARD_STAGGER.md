# 방어형 패링 경직: C 자세 + A 번개

2026-10-31, 개인 작업 브랜치 `feat/minjae-boss-guard`에 적용.

## 적용 모습

| 형태 | 경직 중에도 유지하는 특징 |
| --- | --- |
| 기본 방어형 | 넓은 단일 검, 원형 방패, 청록 망토·흰 견갑 없음 |
| 검기 계승 | 기계식 원형 손잡이와 이중 칼날, 원형 방패 |
| 상승베기 계승 | 단일 검, 흰 견갑, 문양이 있는 청록 망토 |
| 최종형 | 이중 칼날, 큰 흰 견갑, 청록 망토. 두 계승 순서 공통 |

무릎을 깊게 굽히고 고개와 무기를 내리는 C 자세에 어깨·팔꿈치·무릎 주변의 작은 A 번개를 넣었다.
기존 색상에 RGB 0.82배를 적용하며 최종형의 고유 색상과 불투명도는 유지한다.
실물 방패는 남고 패링으로 파괴된 GD01 보호막은 표시하지 않는다.

## 크기와 방향

- 새 시트의 `Reference`는 크기 보정에만 사용한다. 평상시 외형을 새 그림으로 교체하지 않는다.
- 같은 시트의 서 있는 비교 자세를 기존 보스 높이에 맞춘 뒤, 그 배율을 경직 자세에 적용한다.
  따라서 숙인 자세를 서 있는 높이까지 억지로 확대하지 않는다.
- 실제 실행에서 경직 이미지 높이는 기존 자세의 약 82%다. 무기 방향 때문에 전체 너비는 형태별로 달라진다.
- 원본 에셋은 오른쪽을 향한다. 기존 Artwork의 X축 반전만 사용하고, 경직 이미지에 별도 반전을 중복 적용하지 않는다.
- 스프라이트의 기준점은 두 발 사이와 발바닥이다. 상승베기 계승형은 망토가 발 아래로 늘어지는 12픽셀을 별도로 보정했다.
- 경직 종료 시 기존 스프라이트, 위치, 배율, 회전, 색상으로 복귀한다.
  기본형은 GD01이 깨졌으므로 방패를 든 Guard 대신 원래 Idle로 돌아가는 것이 정상이다.

## 실행 검증

`tests/Unity/KarmaStaggerPlayChecks.cs`를 실행 중인 Unity에서 수행했다.
5개 계승 경로 × 좌우 방향(오른쪽은 체력 40% 강화 상태)을 검사했고 **175개 검증이 통과**했다.

- 실제 가상 키보드 K 입력 → 패링 → GD01 파괴 → 보스 경직.
- 올바른 계승형, 좌우 반전, 발 기준점, 크기, 색상과 고정된 몸 중심.
- 경직 중 실제 피해, 일시정지와 재개, 2초 경직 시간.
- 경직 종료 후 원래 대기 스프라이트·배율·위치·색상 복귀.
- 다음 GD02 및 GD03·GD04·GD05에서 경직 외형이 남지 않음.
- 경직 중 사망과 새 방 시작 시 정리, 게임 코드의 실행 오류 없음.

Unity의 실제 Game 화면 30장을 `output/validation/stagger/`에 저장했다.
파일명은 `형태-방향-before/stunned/after.png`이며 최종형의 반대 계승 순서는 `WardFinalReverse`다.
자동 검증 기록은 `output/validation/guard-stagger-play-validation.txt`에 있다.
원래 이미지와 실제 게임 화면을 비교해 단일/이중 칼날, 망토, 견갑, 방향과 자세 복귀를 직접 확인했다.

기존 `KarmaHeavyStrikePlayChecks.Run`도 다시 실행해 **208개 검증이 통과**했다.
0.5초 입력 창, 강화 상태, 패링 실패 피격 기절, GD01 해제, 검기 계승·체력 50% 충격파 조건을 포함한다.
이번 변경 후 통과한 경직·GD02 검증은 합계 **383개**다.

## 파일

- 에셋: `Assets/K4RMA/Resources/K4RMAArtwork/Sheets/Stagger/`의 네 PNG 및 Unity 메타데이터.
- 생성 도구와 전체 프롬프트: `docs/artwork/guard-stagger-generation.json`.
- Unity 가져오기/기준점 재현: `tools/unity/ImportGuardStagger.cs`.
- 표시 처리: `KarmaCharacterAnimator`의 `ConfigureHeavyStrike`, `GuardianPose`, `Die`.

Unity 편집 도구의 한글 경로 관련 임시 스크립트 컴파일 오류는 도메인 재컴파일 후 정상 처리됐다.
위 실행 검증은 그 이후 성공한 실제 게임 실행 결과다.
Console에는 UnityEditor.QuickInstall의 한글 경로/Assembly.CodeBase 인코딩 예외가 남아 있다.
따라서 Console 전체가 오류 0개라는 뜻은 아니다. 이번 검증에서 게임 코드의 실행 오류는 관찰되지 않았다.
