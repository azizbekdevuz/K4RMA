# K4RMA Production Art v1

최신 Notion의 고유화·4수호자 시련·원형 누적 계승 반영. 마지막 상대는 수호자.

## 구성
- 생성 PNG 45개 / 고유 생성 이미지 44개: 실외·실내 하늘을 같은 원본으로 재사용.
- 주인공 20 핵심 포즈.
- 수호자 3종 각각 12 뷰·포즈 + 미계승 기본형8포즈.
- 수호자 외형13종 + 계승 부품3종 시트.
- 플레이어12·수호자12·피격8·고유화12개의 효과 슬롯.
- 실외13·실내10개 parallax 레이어 파일 + 환경 완성 구성2장.
- 소품·전경16슬롯, UI/HUD시트, 단색 기술아이콘6개.
- 고유화 선택 / 타이틀·메뉴 / 클리어·패배·전환·승리4화면 시트.
- 실외·실내·최종전 게임플레이 Mockup3장.
- 첨부 원본6장 보존.
- 전체175개 제작 명세 / 스타일 가이드 / 생성 사양 / 파일·alpha 검사 결과 / parallax 배치 초기값.

## 사용 경계
이 세트는 제작용 원화·핵심 포즈·독립 배경 레이어·화면 구성 세트. 완성된 연속 애니메이션·스프라이트 절단·리깅·Unity Prefab/Scene은 포함하지 않음. Manifest 프레임 수는 제작 목표. 모든175단위의 연속 프레임이 완성됐다는 의미가 아님.
화면 Mockup의 텍스트는 구성 참조. 실제 UI 텍스트는 TMP로 입력. 고유화 UI는 첫 시련 이후3개 선택 상태를 보여줌. 이후 이미 고유화한 원형을 제거하여 2개→1개 선택 표시.
레이어는 단독 PNG이나 자동합성으로 완성 배경을 픽셀 단위로 복원하는 세트가 아님. 위치·겹침·바닥높이·틈새는 Scene 합성 단계에서 맞춤. 레이어 상단/하단 경계에 투명한 여백 존재. 레이어 전체를 임의로 tight crop하면 공유 좌표가 달라짐.
실외 floor는 목표80%보다 위에 생성되어 parallax-layout.json에 초기 offset 기록. 실내 window frame 안의 격자가 배경 기둥이므로 Gameplay Layer 뒤에 배치.

## Unity에 적용
1. RGBA Sprite(2D and UI), Bilinear, mipmaps off, 초기 압축 없음. 실제 alpha를 사용. 파일명별 실제크기는 image-file-index.json 참조. 권장 크기와 실제 출력크기는 구분.
2. 캐릭터·VFX·소품 시트는 Sprite Editor에서 수동 사각형 분리. 도안 위치는 균일 프레임 간격으로 완전히 보정되지 않았으므로 단순 Grid 자동분리를 최종 애니메이션으로 취급하지 않음.
3. 캐릭터 발 기준 pivot 통일, 신장 정렬. 공격 준비→실행→회복 사이 필요한 중간 프레임 추가. VFX는 무기접점 pivot으로 별도 자식 SpriteRenderer.
4. 원형 검기·상승베기·방어의 효과와 고유 동작 관통베기·체공·반격을 별도 상태로 연결. 고유화된 원형 버튼 제거, 고유 효과 활성 표시.
5. 환경은 공통캔버스·center pivot·같은 PPU로 가져온 후 parallax-layout.json의 초기 바닥 offset 적용. 화면 가장자리·원경 빈 공간을 확인하며 Transform 미세 조정. 반복 타일링을 전제로 하지 않는 원화.
6. BG→MG→GameplayFloor→Guardian→Player→VFX→FG→HUD 순서. 보스 디자인에서 추가기술은 부품 교체·자식Sprite로 분리할 경우 원형 identity 유지.

## 검수 결과
- PNG 열기·파일 해시 기록 완료. 투명 에셋 전부 실제 alpha=0 픽셀 확인.
- 배경 레이어 공통 캔버스·16:9 근사 비율 확인. 1920×1080은 권장 구성이고 실제 출력은1672×941 등으로 기록.
- 원경과 전경의 불필요한 캐릭터 포함 출력 제외·재생성.
- 최종 Mockup의 과도한 보스 크기·적색HP·과다 파편을 수정.
- 아이콘 내부 alpha=0 확인. 미리보기에서 보이는 RGB의 diffuse 밝기 중 일부는 완전히 투명한 영역이므로 Unity alpha 표시를 기준으로 판단.
- Unity 실행·애니메이션 루프·24px 아이콘·실제 parallax 합성 검증은 수행하지 않음.

## 화면 평가
최종전: 작은 플레이어, 명확히 큰 수호자, 넓은 전투영역, ivory HP, 긴 월광 참격의 단일 초점 유지. 손그림 목재 수호자와 동일 주인공의 원화 방향 유지. 실제 움직임의 타격감은 공격 판정·히트스톱·사운드·프레임 타이밍과 함께 결정되며 정지 Mockup만으로 검증 불가.
