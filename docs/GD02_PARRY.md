# GD02 강공격 · 붉은 빛 패링

개인 작업 브랜치: `feat/minjae-boss-guard`

## 적용 대상

방어형을 처음 계승한 모든 경로에 같은 GD02 판정을 사용한다.

| 스테이지 | 보스 외형 | 동작 리소스 |
| --- | --- | --- |
| 2 | 기본 방어형 | Ward |
| 3 | 방어형 + 검기 | WardWave |
| 3 | 방어형 + 상승베기 | WardRise |
| 최종 | 방어형 → 검기 → 상승베기 | WardFinal |
| 최종 | 방어형 → 상승베기 → 검기 | WardFinal |

리소스 위치: `Assets/K4RMA/Resources/K4RMAArtwork/Sheets/GD02/`.
각 형태는 검을 든 준비 자세, 내려베기, 마무리 자세를 사용한다.
손의 위치는 형태별 준비 자세에 맞추며, 보스의 좌우 반전을 함께 적용한다.
선택한 C 이펙트는 `ParryRed.png`다. 큰 공격 범위와 구분되도록 손·손잡이 근처에 작게 표시한다.
손잡이의 중심에 불투명한 C 섬광과 별도의 붉은 가산 발광을 겹친다.
신호가 보이는 0.5초 동안 중심 섬광은 사라지거나 어두워지지 않는다. 공격 그림보다 앞에 표시한다.
작은 Game 뷰에서도 확인할 수 있도록 발광 위치와 크기를 실제 화면에서 검증한다.

## 플레이 흐름

1. 검을 머리 위로 든다. 전체 예고는 기존 배율 기준 일반 약 0.81초, 강화 약 0.66초다.
2. 마지막 **0.5초** 동안 붉은 빛이 나타난다. 강화 상태에서도 이 구간은 짧아지지 않는다.
3. 빛이 보일 때 K를 한 번 누르면 이번 내려베기의 패링 입력을 저장한다.
4. 빛이 꺼지는 순간 큰 내려베기가 시작된다. 공격 판정은 0.18초 유지된다.
5. 실제로 공격 범위에 닿으면 저장한 입력을 소비해 기존 반격 판정을 실행한다.
6. 패링 성공 시 피해 없이 보스의 방어막을 깨고 기존 2초 무력화를 적용한다.
7. 패링하지 않고 실제 피해를 받으면 플레이어가 **1초 기절**한다.

후속 지면 충격파는 **검기를 계승했고 현재 체력이 최대 체력의 50% 이하일 때만** 발동한다.
기본 방어형과 방어형+상승베기는 발동하지 않는다. 방어형+검기와 두 최종 계승 순서는 조건을 만족하면 발동한다.
일반 강화 페이즈의 체력 기준을 바꿔도 충격파 기준은 50%로 유지된다.
내려베기를 패링하면 패턴이 중단되므로 충격파도 나오지 않는다.
충격파 자체는 일반 K 반격으로 막을 수 있지만 GD01 파괴나 보스 무력화는 발생하지 않는다.
붉은 빛에서 저장한 패링 입력은 내려베기 전용이며 충격파에는 이어지지 않는다.

GD01은 각 방어형 스테이지 시작부터 켜진다. 회피·피격·후딜레이·다른 패턴 전환으로는 사라지지 않는다.
전투 중 GD02 내려베기 패링 성공으로만 깨지며, 이후 8초 대기와 0.8초 생성 예고를 거쳐 재생성된다.

빛이 나오기 전 입력은 저장하지 않는다. 다만 너무 일찍 누른 일반 반격의 재사용 대기 시간이 남아 있어도,
붉은 빛이 보이는 동안 다시 누른 K는 받아들인다. 일반 반격의 기본 판정 시간은 그대로 0.18초다.
일시정지는 빛의 남은 시간을 보존한다. 공격 중단·종료·새 공격 시작 시 저장한 입력을 지운다.
공격이 빗나가면 원격으로 패링이 발생하지 않으며, 다음 공격에 입력이 남지 않는다.
방어막으로 막거나 무적으로 회피해 피해를 받지 않으면 기절도 발생하지 않는다.

## 코드 확인 순서

- `KarmaEnemy.WardSteps.cs / RisingBarrier`: GD01이 남은 상태에서 후방 회피를 감지하면 지면을 유지한 채 GD02로 전환한다.
- `KarmaEnemy.Ward.cs / HeavyStrike`: 준비 → 빛/입력 창 → 내려베기 → 후딜레이.
- `KarmaEssences.cs / TryCounter`: K 입력이 현재 GD02의 빛 구간이면 입력을 저장한다.
- `KarmaEnemy.Presentation.cs / TryAttackHit`: 실제 접촉에서 저장 입력을 소비하고, 실제 피해에만 기절을 적용한다.
- `KarmaHeavyStrikeMotion.cs`: 계승 형태별 3개 포즈와 손 위치를 연결한다.
- `KarmaEnemy.StateMachine.cs`: 패링 중단과 패턴 종료 시 남은 상태를 정리한다.

조정 값은 `KarmaConfig.asset`의 Boss Tuning에 있다.
`heavyParryCueSeconds = 0.5`, `heavyHitStunSeconds = 1`.
기존 `parryStunSeconds = 2`는 패링 성공 시 **보스** 무력화 시간이다.
