## LOCK-01 주인공
첨부 캐릭터 시트 최우선. 검은 묶음 머리·옆머리·작은 둥근 얼굴·남색 짧은 소매 도복·짙은 하카마·ivory 허리띠·발목 감싸기·일본도. 4~4.5등신 목표, 기존 얼굴과 비율을 우선. 표정 확대컷 이외 얼굴 디테일 최소. 오른쪽 기준 측면 제작; 왼쪽은 flipX, 비대칭이 중요한 포즈는 별도. 캐릭터와 slash를 한 이미지에 굽지 않음.

## LOCK-02 수호자
wave: 긴 판목 신체·각진 얼굴·남색 로프·긴 검. rise: 청록 띠·긴 관절·상향 목재 날개·곡선 무기. ward: 넓고 낮은 몸체·큰 원형 방패·굵은 로프. 과한 목재 잔결은 게임용에서는 생략. 미계승 기본형은 공통 목재·관절·가슴 코어의 중립 검사, 날개/방패/원거리 blade module 없음.
추가 기술은 별도 부품: 검기=수평 blade rails, 상승=상향 fins·천, 방어=동심원 shield parts. 주력 신체와 무기는 유지.

## 선과 명암
1920×1080 최종 화면 기준 캐릭터 외곽 1.5–2px, 내부 0.75–1px, 배경 0.5–1px. 원본을 확대 제작할 때 같은 배수 적용. 배경 저대비 큰 형태, 캐릭터 2단 명암, slash 거의 흰색. 안개가 플레이어를 덮지 않음. 보스 외곽 moon rim, 플레이어 얼굴·띠·무기 밝게. 게임용 원화에 콘셉트 시트의 촘촘한 크로스해칭을 그대로 이식하지 않음.

## LOCK-03 공격
하나의 큰 crescent brush, 가는 시작→넓은 중간→뾰족한 끝. 중심 ivory white, 가장자리는 희미한 moon blue/gold. 기본베기 폭 1.8H, 강공격 2.5H, 검기 3.2H, 상승 2.2H. H는 플레이어 몸높이. 판정/색/준비동작을 분리. 무작위 particle cloud 금지. 피격 spark만 짧게. 방어는 얇은 2~3 동심원.

## LOCK-04 공간
정면 횡스크롤, 16:9, 바닥 화면 y=80%. 플레이어 8–10% 화면높이, 보스 24–32%, 전투 중앙 너비 70% 비움. 가까운 바닥 명확, 원경은 대비 낮춤. 등불은 화면 면적 3% 이하의 따뜻한 포인트. 모든 parallax 레이어 공유 캔버스·지평선·기준점. 산·숲·기둥·foreground를 개별 파일로 제작; 하나의 완성 배경을 자른 띠를 레이어라고 부르지 않음.

## LOCK-05 UI
navy 반투명 panel, ivory 얇은 선, 최소 작은 장식, 텍스트 중심. 글자는 에셋에 굽지 않고 TMP. 3원형 아이콘은 수평초승달/수직초승달/동심원. 선택창: 검기→관통베기, 상승베기→체공, 방어→반격 + 다음 수호자 계승 원형 표시. 원형 감소와 새 동작 증가 동시 표현.

## Unity 적용 및 QA
SpriteRenderer: 주인공 발 중앙 pivot, VFX 무기 접점 pivot. PPU 256 제안, 몸높이 월드 1.5–2유닛 목표로 조정. 포즈별 자동 tight crop 금지; 같은 셀·발 기준 고정. spritesheet의 글자/눈금은 게임용 출력에서 제외. RGBA 실제 alpha 확인. Filter Bilinear, mipmap off, 초깃값 압축 없음. 애니메이션 시작 12fps, 공격 프레임 시간은 전투 판정과 함께 조정. sorting: BG→MG→GameplayFloor→Guardian→Player→VFX→FG→HUD.
포즈 시트는 연속 재생 검증 전까지 animation-ready로 표시하지 않음. 여러 포즈가 있다는 것과 프레임 정렬·무게중심·루프 연속성이 검증됐다는 것은 별개. 생성된 모형 화면은 Unity 실행 캡처가 아님. 최종 검증: 25% 축소 실루엣, alpha 테두리, 한 프레임 검/관절 수, 1초 방향 판독, 전경 가림, 바닥 접지, 주인공 identity.
